# Project Context

## Project Overview
Atoms Demo - A web application simulating the core workflow of the Atoms platform: Chat → Code Generation → Publish. Features an IDE-like dark theme interface with chat panel, code editor with syntax highlighting, live preview, and publish deployment flow.

## Constraints
- Design: Dark theme IDE-like interface, blue-purple accent colors (#6366f1, #8b5cf6), monospace fonts for code areas
- Layout: Three-panel layout - chat (left), code editor (top-right), preview (bottom-right)
- Typography: Inter for UI, JetBrains Mono / monospace for code
- Color Scheme: Dark background (#0f0f23, #1a1a2e), accent gradient (indigo to purple)
- Images: 4 generated images used for logo and decorative elements
