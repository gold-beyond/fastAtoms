# Project Summary
The Atoms project is a sophisticated web application tailored for digital marketers and content creators, enabling them to effortlessly design and manage interactive landing pages. It prioritizes secure user authentication and data persistence, allowing users to safely store their projects and conversations. This collaborative platform employs a modern technology stack to enhance content generation, project management, and AI-driven interactions, thereby serving as an indispensable tool for optimizing digital marketing strategies.

# Project Module Description
The Atoms project comprises several functional modules:
- **Authentication Module**: Handles user registration, login, and session management through Atoms Cloud.
- **Data Persistence Module**: Utilizes PostgreSQL for secure storage of user conversations and project data.
- **Chat Module**: Provides an AI assistant interface for user interactions, enabling conversation saving and retrieval.
- **Project Management Module**: Facilitates the creation, viewing, and management of user projects.
- **UI Components**: A library of reusable UI components for frontend development.
- **AI Proxy Module**: Proxies requests to external AI providers, allowing the use of custom AI model API keys.
- **Conversation Sidebar**: Enhances user experience by managing conversation history in a dedicated sidebar.
- **Multi-Agent System**: Supports multiple agents collaborating on tasks, including agent definitions, task management, and context sharing.
- **Light Theme Design Document**: Outlines specifications for transitioning the current dark theme to a light theme, ensuring consistency with the Atoms platform's design.

# Technology Stack
- **Backend**: Python, PostgreSQL, Alembic for migrations.
- **Frontend**: React, TypeScript, Vite, Tailwind CSS.
- **Cloud Services**: Atoms Cloud for authentication and data storage.

# Usage
To set up the project, follow these steps:
1. **Install Dependencies**:
   - Navigate to the backend directory and run:
     ```
     pip install -r requirements.txt
     ```
   - Navigate to the frontend directory and run:
     ```
     pnpm install
     ```
   
2. **Build the Project**:
   - For the backend, run:
     ```
     python main.py
     ```
   - For the frontend, run:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the backend service.
   - Start the frontend service.
