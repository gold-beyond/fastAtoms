# Project Summary
The Atoms project is a web application that allows users to easily create and manage interactive landing pages. It focuses on providing robust user authentication and data persistence, ensuring secure storage of user projects and conversations. The application enhances collaboration among digital marketers and content creators, facilitating streamlined content generation and project management through a modern technology stack.

# Project Module Description
The Atoms project comprises the following functional modules:
- **Authentication Module**: Handles user registration, login, and session management via Atoms Cloud.
- **Data Persistence Module**: Utilizes PostgreSQL for storing user conversations and project data.
- **Chat Module**: Provides an AI assistant interface for user interactions, enabling conversation saving and retrieval.
- **Project Management Module**: Allows users to create, view, and manage their projects within the application.
- **UI Components**: A library of reusable UI components for frontend development.
- **AI Proxy Module**: Facilitates the use of custom AI model API keys by proxying requests to external AI providers.

# Technology Stack
- **Backend**: Python, PostgreSQL, Alembic for migrations.
- **Frontend**: React, TypeScript, Vite, Tailwind CSS.
- **Cloud Services**: Atoms Cloud for authentication and data storage.

# Usage
To set up the project, follow these steps:
1. **Install Dependencies**:
   - Navigate to the backend directory and run:
     ```
     pip install -r requirements.txt
     ```
   - Navigate to the frontend directory and run:
     ```
     pnpm install
     ```
   
2. **Build the Project**:
   - For the backend, run:
     ```
     python main.py
     ```
   - For the frontend, run:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the backend service.
   - Start the frontend service.
