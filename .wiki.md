# Project Summary
The project is a web application designed to provide a modern and interactive platform for users to create landing pages efficiently. It integrates a chat interface for user assistance, a code editor for real-time coding, and a preview panel to visualize the output. The application aims to simplify the process of building responsive landing pages with a focus on user experience and design aesthetics.

# Project Module Description
- **ChatPanel**: Provides a chat interface where users can interact with an AI assistant for guidance and code generation.
- **CodeEditor**: A code editor that allows users to write and edit HTML, CSS, and JavaScript code with syntax highlighting and file management.
- **PreviewPanel**: Displays a live preview of the landing page being developed, with options to switch between desktop and mobile views.
- **PublishDialog**: A dialog that facilitates the publishing process of the landing page to a global CDN.

# Technology Stack
- **React**: Frontend library for building user interfaces.
- **TypeScript**: Superset of JavaScript for type safety.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Vite**: Build tool for faster development and production builds.
- **PostCSS**: Tool for transforming CSS with JavaScript plugins.
- **ESLint**: Linting utility for JavaScript and TypeScript.

# Usage
1. Install dependencies:
   ```bash
   cd app/frontend
   pnpm install
   ```
2. Build the project:
   ```bash
   pnpm run build
   ```
3. Run the application:
   ```bash
   pnpm run start
   ```
