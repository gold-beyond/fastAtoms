# Project Summary
The Atoms project is a web application designed for digital marketers and content creators to easily create and manage interactive landing pages. It emphasizes secure user authentication and data persistence, ensuring that user projects and conversations are safely stored. As a collaborative platform, it enhances content generation and project management using a modern technology stack, including integrated AI capabilities for streamlined user interactions.

# Project Module Description
The Atoms project consists of the following functional modules:
- **Authentication Module**: Manages user registration, login, and session management via Atoms Cloud.
- **Data Persistence Module**: Utilizes PostgreSQL for secure storage of user conversations and project data.
- **Chat Module**: Features an AI assistant interface for user interactions, allowing for conversation saving and retrieval.
- **Project Management Module**: Enables the creation, viewing, and management of user projects.
- **UI Components**: A library of reusable UI components for frontend development.
- **AI Proxy Module**: Facilitates the use of Atoms Cloud’s built-in AI capabilities without needing external API keys.
- **Conversation Sidebar**: A dedicated sidebar for managing conversation history, enhancing user experience.

# File Description Inventory
- **app/backend/README.md**: Instructions for setting up and running the backend.
- **app/frontend/README.md**: Instructions for setting up and running the frontend.
- **app/backend/lambda_handler.py**: Contains the AWS Lambda function for serverless operations.
- **app/frontend/src/components/**: Contains reusable UI components for the frontend.
- **app/frontend/src/hooks/**: Custom React hooks for state management and side effects.
- **app/frontend/src/lib/**: Utility functions and shared instances, including the web SDK client.
- **app/frontend/src/components/ChatPanel.tsx**: Updated to use Atoms Cloud's AI capabilities directly.
- **app/frontend/src/components/ConversationSidebar.tsx**: New component for displaying conversation history in a permanent sidebar.
- **app/frontend/src/pages/Index.tsx**: Updated to integrate ConversationSidebar and manage conversation states.
- **app/backend/services/ai_proxy.py**: Modified to use Atoms Cloud's AI capabilities as a fallback when no external API key is provided.
- **app/backend/routers/ai_proxy.py**: Router for handling AI proxy requests.

# Technology Stack
- **Backend**: Python, PostgreSQL, Alembic for migrations.
- **Frontend**: React, TypeScript, Vite, Tailwind CSS.
- **Cloud Services**: Atoms Cloud for authentication and data storage.

# Usage
To set up the project, follow these steps:
1. **Install Dependencies**:
   - Navigate to the backend directory and run:
     ```
     pip install -r requirements.txt
     ```
   - Navigate to the frontend directory and run:
     ```
     pnpm install
     ```
   
2. **Build the Project**:
   - For the backend, run:
     ```
     python main.py
     ```
   - For the frontend, run:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the backend service.
   - Start the frontend service.
