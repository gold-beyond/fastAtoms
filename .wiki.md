# Project Summary
The Atoms project is a web application that enables users to create and manage interactive landing pages effortlessly. It features robust user authentication and data persistence, ensuring secure storage of projects and conversations. By leveraging a modern technology stack, the application enhances collaboration and streamlines content generation, making it an essential tool for digital marketers and content creators.

# Project Module Description
The Atoms project consists of the following functional modules:
- **Authentication Module**: Handles user registration, login, and session management using Atoms Cloud.
- **Data Persistence Module**: Utilizes PostgreSQL for storing user conversations and project data.
- **Chat Module**: Provides an AI assistant interface for user interactions, allowing for conversation saving and retrieval.
- **Project Management Module**: Enables users to create, view, and manage their projects within the application.
- **UI Components**: A library of reusable UI components for frontend development.
- **AI Proxy Module**: Allows users to utilize their own AI model API keys by proxying requests to external AI providers.

# File Description Inventory
- **app/backend/README.md**: Instructions for setting up and running the backend.
- **app/frontend/README.md**: Instructions for setting up and running the frontend.
- **app/backend/lambda_handler.py**: Contains the AWS Lambda function for serverless operations.
- **app/frontend/src/components/**: Contains reusable UI components for the frontend.
- **app/frontend/src/hooks/**: Custom React hooks for state management and side effects.
- **app/frontend/src/lib/**: Utility functions and shared instances, such as the web SDK client.
- **app/frontend/src/components/ChatPanel.tsx**: Updated to remove static demo content and implement a welcoming empty state for user input.
- **app/backend/services/ai_proxy.py**: Service that proxies chat requests to external AI providers.
- **app/backend/routers/ai_proxy.py**: Router for handling AI proxy requests.

# Technology Stack
- **Backend**: Python, PostgreSQL, Alembic for migrations.
- **Frontend**: React, TypeScript, Vite, Tailwind CSS.
- **Cloud Services**: Atoms Cloud for authentication and data storage.

# Usage
To set up the project, follow these steps:
1. **Install Dependencies**:
   - Navigate to the backend directory and run:
     ```
     pip install -r requirements.txt
     ```
   - Navigate to the frontend directory and run:
     ```
     pnpm install
     ```
   
2. **Build the Project**:
   - For the backend, run:
     ```
     python main.py
     ```
   - For the frontend, run:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the backend service.
   - Start the frontend service.
